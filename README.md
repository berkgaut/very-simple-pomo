# pomo: Yes, Another Pomodoro Timer, This Time Done Unix Way

![LLM generated](https://img.shields.io/badge/LLM--generated-blue?style=flat-square)


==Warning: while prose in this repo is written by a human (me), the code is generated by an LLM==

A tiny Go program I designed and then let LLM to generate, with a dual purpose:
- Have an improved version of a pomodorro timer shell-script
- Learn a bit of Golang

License-wise, the prose in this repo is CC-BY, while the LLM-generated code I believe is in the grey zone (as of 2026-05)

## Basic Use

`pomo 15` - start a timer for 15 minutes; if there is a running timer, stop it

`pomo stop` - stop the timer

`pomo remaining` - print remaining time in mm:ss format; if timer is paused, prepends `P` (e.g. `P02:22`); if timer is not running, exit with code 127

`pomo pause` - pause the running timer; exit with code 127 if no timer is running or it is already paused

`pomo cont` - resume a paused timer; exit with code 127 if no timer is paused

`pomo add 5` - add 5 minutes to the running (or paused) timer; if timer is not running, exit with code 127

## Starship Integration

pomo plays nice with PS1 customizations, incl. https://starship.rs/

```toml
[custom.pomo]
command = "pomo remaining"
when = "pomo remaining"
format = "[ $output ]($style) "
style = "bold red"
```

## Journal

pomo keeps track of ran out timers in `~/.pomo/journal`

example:
```text
2026-05-03T08:00:12 15:00 COMPLETE
2026-05-03T08:00:12 15:00 CANCELED
```

`pomo NN` could be supplemented with a journal comment, `pomo 15 "plan the day"` would appear in the journal as

```text
2026-05-03T08:16:00 15:00 COMPLETE plan the day
```

`pomo list` - print todays journal entries

## Config

Config is stored in `~/.pomo/config.toml`

### default_notification

Notification message template used when a timer with no comment ran out.

### notification

Notification message template used when a timer with a comment ran out. 

Template variables:
 - `{{.Comment}}`

### notification_command

A command to deliver the notification. List of template strings, where the first element is the command to execute, the remaining elements are command arguments.

Template variables:
 - `{{.Message}}`
